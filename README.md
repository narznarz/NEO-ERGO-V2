# Neo Ergo Tri-mode — VIA 커스텀 펌웨어

## ⚠️ 주의

<span style="color:red">모든 문제에 책임지지 않습니다. 충분히 위험을 인지하고 시작하세요.</span>
<span style="color:red">키 레이아웃 설정을 저장해두세요. 펌웨어를 새로 깔면 모든 설정이 내장된 기본 키 설정으로 덮어써집니다.</span>

작성자: NARZ  
최신 버전: **v2.9** (`NeoErgo_trimode_via_v2.9_NARZ.bin`)

## ✨ 특징

순정에서는 못 하던 걸 몇 가지 더했습니다.

1. 무선으로 연결해도 MT, LT 같은 고급 키코드를 쓸 수 있습니다.

2. **유선이랑 무선의 LED 절전을 다르게 처리합니다.**
   - 유선은 키 입력이 없으면 **10분** 뒤 LED가 꺼집니다. MCU는 깨어 있어서 USB 연결은 그대로 유지됩니다.
   - 무선은 배터리를 아끼려고 **2분** 뒤 절전에 들어갑니다.

3. **LED가 3초에 걸쳐 서서히 꺼지고 켜집니다.** 갑자기 확 꺼지거나 켜지지 않아서 보기에도 편합니다.

## 이 펌웨어가 해결한 것

Neo Ergo tri-mode 순정 펌웨어도 VIA를 지원은 합니다. 다만 무선으로 연결하면 일부 고급 키코드 설정이 제대로 먹지 않더군요. VIA 반쪽 지원을 좀 더 완전하게 만들고, LED 절전과 페이드까지 손봤습니다.

## 버전 이력

### v2.0
- 무선 LED 및 핵심 코어 - 절전 2분 타이머, 무선 모듈 20분 타이머.
- 유선 LED 꺼짐 10분 타이머

## 무선에서 지원하는 키

- MT / LT (Mod-Tap / Layer-Tap) 등
- LSG / MEH 등 각종 조합키

## 플래시 방법

1. [QMK Toolbox](https://github.com/qmk/qmk_toolbox/releases) 관리자 권한으로 실행
2. 배터리 스위치 OFF
3. ESC(0,0) 누른 채 USB-C 연결 → DFU 모드. 붉은색 드라이버 관련 메시지가 뜨면 WinUSB 드라이버 설치 버튼으로 설치
4. `NeoErgo_trimode_via_v2.9_NARZ.bin` 선택 → Flash
5. EXIT DFU 클릭


## 변경 내역

## v2.9

LED 동작을 최적화함. 연결 모드에 따라 상단 영역 LED 하나만 색으로 표시하고, RGB 토글로 상단·왼쪽·내부의 LED 켜고 끌 수 있습니다. 
총 8가지 조합이라 조금 번거롭지만 'RGB 토글'키를 누르다보면 결국 원하는 부분의 LED만 켤 수 있습니다.
RGB속도를 최저로 낮춰도 멈추지는 않던 움직임을 확실히 멈추게 하고 이 상태에서 채도, 밝기, 색상변경(특정 RGB모드 한정)을 조절 할 수 있습니다.

전원을 연결하거나 절전에서 깨어날 때 밝기가 서서히 올라가서 고급스러움을 더했습니다.
물론, 키 입력은 즉시 처리됩니다.

무선 절전 알고리즘을 최적화 했습니다.
